## The word

**Unsubscribe**

One word, eleven letters, no punctuation, no caption needed: an ex summed up as the spam you finally opt out of. It lands at a glance, it is not the obvious insult, and anyone who has had an ex has felt the urge to hit that button.

## How it works

`main.py` (Python 3 standard library only) writes exactly that one word — nothing else, no trailing newline — to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```

Output: `Unsubscribe` (11 bytes, 1 word, well under the 111-character gate).
